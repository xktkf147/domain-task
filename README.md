# 자기 도메인 업무 분해 예시

## [도메인 맥락]
나는 **쇼핑몰 회원·주문 데이터(MariaDB)** 도메인 **1년 미만**(학습 1개월 차)이고,
**회원 가입·주문 SQL 실행 중 발생하는 오류 로그를 확인하고 정리하는** 작업을 자동화/정리하고 싶습니다.

## [네 동작 분석]
1. **분해**: ① 회원 가입·주문 등록 SQL 실행 → ② 에러 발생 시 붙잡기 → ③ 에러 정보를 오류 기록 테이블에 저장 → ④ 하루 동안 쌓인 에러를 모아서 보기
2. **패턴**: 회원 가입·주문에서 나는 에러는 대부분 *중복 아이디(1062), 필수값 누락(1048), 없는 상품·회원 참조(1452)* 처럼 반복되며, 모든 에러는 *에러 번호 + 상태코드 + 메시지* 3개를 가진다
3. **추상화**: 에러 번호, 메시지, 작업 이름(예: 회원가입, 주문등록), 발생 시간 4가지만 저장한다
4. **알고리즘**: 회원 가입·주문 SQL 실행 → 실패하면 오류 기록 테이블에 INSERT → 작업 이름·에러 번호별로 개수를 세어 많이 난 순서대로 보여주기

## [출력 요구]
**표 + SQL 예제 코드(주석 포함)** 형식으로, 한국어로.

## [검증 기준]
**SQL 기초(SELECT, INSERT, CREATE)만 아는 쇼핑몰 백엔드 신입 개발자**가
"**그대로 복사해서 MariaDB에 실행할 수 있고, 어떤 작업에서 어떤 에러가 가장 많이 났는지 바로 알 수 있다**"라고 평가할 것.
